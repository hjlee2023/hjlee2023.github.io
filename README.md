## 주간 PubMed 서재

PubMed 트렌딩에서 그 주의 논문을 골라 한국어 해설과 원문 abstract 정독으로 엮은 주간 서재.

**→ https://hjlee2023.github.io/pubmed/**

선정은 PubMed 자체 트렌딩 순위(열람 기준)에 저널·논문유형·최신성을 가중해 매기고, 여기에 고티어 기초·중개 저널의 그 주 신착과 '지금 다시 읽히는 고전'을 따로 더한다.

각 논문 abstract 의 저작권은 해당 출판사·저자에게 있습니다. 이 사이트는 학습 목적의 인용과 한국어 해설이며, 원문은 각 논문에 달린 PubMed 링크에서 보실 수 있습니다.

## 주간 경제학 서재

경제학 워킹페이퍼 중 그 주에 여러 분야 편집자가 동시에 주목한 것을 골라 한국어 해설과 원문 초록 정독으로 엮은 주간 서재.

**→ https://hjlee2023.github.io/econ/**

출처는 NEP(New Economics Papers) — RePEc 신착을 분야별 편집자가 손으로 골라 내는 주간 리포트다. 거시·금융·투자 16종에서 후보를 모으고, 여러 분야 편집자가 동시에 고른 논문과 최상위 기관(NBER·CEPR·BIS·IMF·중앙은행) 신착을 가중해 추린다.

각 논문 초록의 저작권은 해당 저자·발행기관에 있습니다. 이 사이트는 학습 목적의 인용과 한국어 해설이며, 원문은 각 논문에 달린 RePEc 링크에서 보실 수 있습니다.

|---|---|---|
