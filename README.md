## 주간 경제학 서재

경제학 워킹페이퍼를 NEP 분야 리포트에서 골라 한국어 해설과 원문 초록 정독으로 엮은 주간 서재.

**→ https://hjlee2023.github.io/econ/** · 새 호 알림(피드): https://hjlee2023.github.io/econ/feed.xml

논문은 NEP(New Economics Papers)에서 고른다. NEP 는 RePEc 에 새로 올라온 논문을 분야별 편집자가 주제에 따라 골라 매주 내는 리포트다. 이 중 거시·금융·투자 분야 16종에서 후보를 모으고, 여러 분야 리포트에 함께 실린 논문과 주요 기관의 신착에 가중치를 둔다. 여러 리포트에 실렸다는 것은 주제가 여러 분야에 걸친다는 뜻이고 품질 평가는 아니다.

각 논문 초록의 저작권은 해당 저자·발행기관에 있습니다. 이 사이트는 학습 목적의 인용과 한국어 해설이며, 원문은 각 논문에 달린 RePEc 링크에서 보실 수 있습니다.
