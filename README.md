## 주간 심리학·뇌과학 서재

뇌와 마음을 다룬 그 주의 논문을 PubMed 에서 골라 한국어 해설과 원문 abstract 정독으로 엮은 주간 서재.

**→ https://hjlee2023.github.io/psych/** · 새 호 알림(피드): https://hjlee2023.github.io/psych/feed.xml

심리학, 신경과학, 정신의학, 신경과 논문을 싣는다. PubMed 트렌딩 상위 500편에서 뇌와 마음을 다룬 논문을 골라 저널·논문유형·최신성을 가중해 매기고, 신경·심리 저널과 종합지의 그 주 신착, 트렌딩에 다시 오른 3년 이상 된 논문을 따로 더한다. 트렌딩은 NCBI 가 최근 활동이 늘어난 논문이라고만 밝히고 산식은 공개하지 않아, 많이 읽혔다는 뜻으로 단정할 수 없다. 주간 PubMed 서재와 겹치는 뇌·마음 논문은 이 서재에 싣는다. 의학·분자 쪽 신경과학은 PubMed 서재 몫이다. PsyArXiv 와 bioRxiv 신경과학의 그 주 프리프린트도 주제 적합도와 연구 위생(사전등록·데이터 공개)으로 골라 싣는데, 동료 심사 전 논문이므로 "미심사 프리프린트"라고 표시하며 인기 지표는 쓰지 않는다.

각 논문 abstract 의 저작권은 해당 출판사·저자에게 있습니다. 이 사이트는 학습 목적의 인용과 한국어 해설이며, 원문은 각 논문에 달린 PubMed 링크에서 보실 수 있습니다.
